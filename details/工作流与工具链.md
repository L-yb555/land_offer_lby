# 个人 AI 工作流与工具链

> 记录日常科研写作与求职投递中实际使用的 AI 工作流，供简历「AI Agent 与文档工作流」技能条目的口径核对。
> 简历投递口径见 [`../baseline.md`](../baseline.md)。

---

## 一、 论文写作工作流

- **编辑语言**：LaTeX / Markdown。
- **工作方式**：通过 CLI 直接阅读与修改稿件，减少编辑器切换成本，保持纯文本可版本管理的写作链路。
- **能力边界认知**：了解大模型在信息组织、初稿生成、格式转换与审校辅助中的能力边界，能够针对科研写作需求拆解任务、设计 Prompt、组织资料输入并完成多轮迭代。

## 二、 求职投递工作流

- **岗位获取**：在 Claude Code 中使用 boss CLI 配合 Chrome 获取岗位信息与 JD。
- **排版语言**：以 LaTeX 作为简历编辑语言。
- **模板制作**：通过 Gemini 制作 PDF 模板。
- **内容更新**：通过 Codex 更新简历内容。
- **本仓库角色**：[`../baseline.md`](../baseline.md) 作为投递内容的事实底稿，[`../resume-skill/`](../resume-skill/) 下的 `resume-role-tailor` 技能负责按 JD 定向改写并生成 Markdown / PDF 成品。
