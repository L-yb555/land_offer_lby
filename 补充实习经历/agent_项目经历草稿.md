# AI Agent 项目经历草稿

以下内容改成更具体的市场常见 Agent 产品形态，避免表述过空。  
建议优先使用“企业知识助手 Agent / RAG 助手 Demo”这类方向，因为它和 AI 应用研发工程师岗位的匹配度最高，也更容易被面试官理解。  
但这仍然是草稿，只有在你真实做过或准备按此补齐 Demo 后再用于正式投递。

## 推荐版本：企业知识助手 Agent Demo

企业知识助手 Agent Demo（草稿，需按真实情况确认）  
2026.01-至今

1. 面向企业知识问答与流程辅助场景，设计并实现一个企业知识助手 Agent 原型，支持基于知识库的问答、任务拆解、信息检索与结果整合，产品形态对标市场常见的 AI 知识助手 / 企业内部 Copilot。
2. 围绕知识增强链路完成文档切分、向量检索、上下文注入与答案生成流程设计，持续优化召回质量、上下文拼接方式与输出稳定性，提升回答相关性与可用性。
3. 基于大模型完成 Prompt 设计与多轮调优，并结合规则兜底与错误重试机制，降低幻觉、答非所问和不稳定输出对用户体验的影响。
4. 设计基础调用链日志与 Case 回放机制，支持对检索结果、上下文质量、模型输出和失败样本进行分析，为后续调优提供依据。
5. 在原型搭建、页面实现、代码重构与调试过程中重度使用 Claude Code、Codex 等 AI 编程工具辅助开发，形成对 AI 协作编程、Prompt 驱动开发与生产级代码约束的实践理解。
